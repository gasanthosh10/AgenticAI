# AgenticAI - Git Commands

## Daily Workflow

### 1. Check changes
git status

### 2. Stage changes
git add .

### 3. Commit changes
git commit -m "Describe today's changes"

### 4. Push to GitHub
git push

### 5. View recent commits
git log --oneline -5

## Repository
GitHub: https://github.com/gasanthosh10/AgenticAI

## Important
Never commit:
- .env
- .venv/
- .venv312/
- __pycache__/
- API keys or secrets
- Large local model files
